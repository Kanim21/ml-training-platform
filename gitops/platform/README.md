# gitops/platform

One directory per component. Each one is synced by an Application in
`gitops/bootstrap/apps/` under the `ml-platform` project.

| Directory | Namespace | What |
| --- | --- | --- |
| `sealed-secrets/` | kube-system | Sealed Secrets controller (pinned release manifest) |
| `cnpg-operator/` | cnpg-system | CloudNativePG operator (pinned release manifest) |
| `seaweedfs/` | storage | S3 object store; buckets `mlflow`, `checkpoints`, `datasets` |
| `mlflow/` | mlflow | MLflow tracking server + its CloudNativePG `Cluster` |

In-cluster endpoints:

- MLflow: `http://mlflow.mlflow.svc:5000`. Artifacts are proxied through the
  server.
- S3: `http://seaweedfs.storage.svc:8333`. Credentials come from the
  `s3-credentials` Secret in each consuming namespace.

Credentials: `make seal-s3` regenerates the S3 key pair as SealedSecrets.
The Postgres credential is generated by CloudNativePG (`mlflow-db-app`). See
[ADR 0004](../../docs/adr/0004-sealed-secrets.md), including the note on
backing up the sealing key before a rebuild.

From outside the cluster (`make mlflow-ui`), set
`MLFLOW_ENABLE_PROXY_MULTIPART_DOWNLOAD=false` in the client; see
[ADR 0005](../../docs/adr/0005-seaweedfs-instead-of-minio.md).
